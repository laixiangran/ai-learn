## 项目开发
安装依赖：
```bash
npm install
```

启动：
```bash
npm run dev
```

访问：
```bash
页面：http://localhost:3000/rag
接口：http://localhost:3000/rag/01_simple_rag
```

## 项目说明

本项目是 AI 应用开发实践项目，将会涵盖 AI 应用开发中涉及到各种技术，包括但不限于提示工程、RAG、模型微调、Agent等等。
